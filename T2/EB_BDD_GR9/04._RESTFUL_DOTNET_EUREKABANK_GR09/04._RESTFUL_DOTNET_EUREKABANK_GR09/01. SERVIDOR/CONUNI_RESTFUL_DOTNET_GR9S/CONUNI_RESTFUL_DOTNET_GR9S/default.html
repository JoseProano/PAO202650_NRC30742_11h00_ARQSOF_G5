📡 Base URL:
📚 Servicio: Core Bancario EurekaBank

🚀 Endpoints Principales

GET /api/corebancario/movimientos/{cuenta} - Obtener movimientos de una cuenta
Ejemplo: /api/corebancario/movimientos/00100001
POST /api/corebancario/deposito?cuenta={cuenta}&importe={importe} - Registrar depósito
Ejemplo: /api/corebancario/deposito?cuenta=00100001&importe=100.50
POST /api/corebancario/retiro?cuenta={cuenta}&importe={importe} - Registrar retiro
Ejemplo: /api/corebancario/retiro?cuenta=00100001&importe=50.25
POST /api/corebancario/transferencia?cuentaOrigen={origen}&cuentaDestino={destino}&importe={importe} - Registrar transferencia
Ejemplo: /api/corebancario/transferencia?cuentaOrigen=00100001&cuentaDestino=00100002&importe=200.00

📋 Descripción de Operaciones

💰 Depósito: Agrega fondos a una cuenta bancaria. El saldo se incrementa y se registra un movimiento tipo '003'.
💸 Retiro: Extrae fondos de una cuenta bancaria. Valida que haya saldo suficiente y registra un movimiento tipo '004'.
🔄 Transferencia: Transfiere fondos entre dos cuentas. Crea dos movimientos: tipo '009' (salida) en origen y tipo '008' (ingreso) en destino.
📊 Movimientos: Consulta el historial completo de transacciones de una cuenta, ordenado por número de movimiento descendente.

📝 Formato de Respuesta

Operaciones (Depósito/Retiro/Transferencia):
{"estado": 1} - Éxito
{"estado": -1} - Error
Movimientos: Array de objetos con la siguiente estructura:
[
  {
    "Cuenta": "00100001",
    "NroMov": 1,
    "Fecha": "2024-01-15T10:30:00",
    "Tipo": "Depósito",
    "Accion": "INGRESO",
    "Importe": 100.50,
    "Tipocodigo": "003",
    "Emplcodigo": "0001",
    "Referencia": ""
  }
]
💡 Nota: Todas las operaciones se realizan con transacciones atómicas en la base de datos.
